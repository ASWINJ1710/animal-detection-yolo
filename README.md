# Animal Detection Using YOLOv8

## Overview
An object detection project that identifies animals in images using YOLOv8 and draws bounding boxes around detected objects.

## Animal Classes
- Buffalo
- Elephant
- Rhino
- Zebra

## Technologies
- Python
- YOLOv8
- Ultralytics
- OpenCV
- Google Colab

## Project Workflow
1. Dataset preparation
2. Bounding-box annotation
3. YOLO model training
4. Model evaluation
5. Animal detection on new images

## Project Notebook
See `animal_detection_yolo.ipynb` for the implementation.

## Limitations
The initial bounding-box annotations were generated automatically and should be reviewed, particularly for Buffalo and Rhino. Model performance depends on annotation quality.

- Improve annotation quality
- Increase detection accuracy
